## Sobre o projeto
O my-app é um aplicativo desenvolvido com Expo para demonstrar três padrões de navegação usando react<br>
a configuração dos navegadores fica separada das telas, permitindo alternar entre os modos pelo arquivo `src/routes/index.jsx`<br>

## Telas
**Stack:** navegação em pilha entre as telas início e produtos, com opção de voltar<br>
**Bottom Tabs:** barra inferior com quatro abas, início, produtos, perfil e configurações<br>
**Drawer:** menu lateral com as opções início, produtos, perfil e configurações, acessível pelo botão de menu e pelo gesto de arrastar a partir da borda da tela<br>

## Como executar
Pré-requisitos:<br>
Node.js e npm instalados<br>
Após isso, clone o git do projeto, instale as dependencias usando `npm install` e depois `npx expo start`
